# IT Support Ticket System

A lightweight ticket triage web app for junior IT support teams. Built to demonstrate IT support workflow, SLA tracking, and remote collaboration skills.

## Features
- Create, view, and update support tickets
- Status workflow: Open → In Progress → Resolved → Closed
- Priority levels: Low, Medium, High, Critical
- SLA countdown per ticket
- Simple SQLite backend, Flask web UI
- Role-based views for agents and managers

## Tech Stack
- Python 3.11+
- Flask
- SQLite
- HTML/CSS/JavaScript

## Run Locally
```bash
pip install -r requirements.txt
python app.py
```
Open http://localhost:5000
